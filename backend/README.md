# Backend EduTech

Esta carpeta contendrá la API del proyecto EduTech.

El backend se conectará con PostgreSQL y servirá rutas para:

- comprobar que el servidor funciona;
- registro e inicio de sesión;
- consulta de cursos;
- compra simulada de cursos;
- consulta de cursos inscritos.

Para ejecutar el backend se usará Node.js con Express.
