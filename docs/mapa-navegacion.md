🔵 Azul (Zona del Alumno): Interfaz para el consumo de contenido. Contiene el panel principal del estudiante, el aula virtual para ver lecciones, el sistema de exámenes y la consulta de certificados.

🟡 Amarillo (Zona del Administrador): Centro de control del sistema. Incluye herramientas para la gestión de usuarios, supervisión global de cursos, auditoría de pagos y configuración técnica de la pasarela.
