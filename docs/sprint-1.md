# Sprint 1 - Plan de trabajo

## Proyecto

EduTech - Plataforma web de cursos.

## Duración del Sprint

Del miércoles 29 de abril al jueves 7 de mayo de 2026.

## Objetivo del Sprint

Organizar y construir la base inicial del proyecto, definiendo actores, requerimientos, navegación, pantallas, wireframes, modelo de base de datos, tecnologías, estructura del proyecto, frontend visual y base de datos inicial.

## Estado al cierre del Sprint 1

Al cierre del Sprint 1, el equipo avanzó principalmente en la documentación y planeación base del sistema.

### Entregas avanzadas

- Actores del sistema.

- Requerimientos funcionales y no funcionales.
- Mapa de navegación.

### Nota de cierre

El Sprint 1 no se considera terminado al cien por ciento, porque algunas actividades quedaron pendientes o requieren correcciones. Sin embargo, sí existe una base documental suficiente para continuar con el siguiente avance del proyecto.
